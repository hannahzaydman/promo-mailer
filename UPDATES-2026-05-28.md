# Updates — May 28, 2026

---

## New Features

### Retry Failed Emails
After a batch send, a **Retry N failed** button appears if any emails errored. Clicking it re-sends only the failed addresses without going back through the full flow. If some still fail, the button reappears with the remaining count.

### Export Preview as CSV
An **Export CSV** button in the preview header downloads a spreadsheet of all queued emails — Release, Name, Email, Code, Subject — for verification before sending.

### Delete Templates
The template bar in each release card now has a **Delete** button alongside Load and Save As. Confirms before deleting and updates all open release cards instantly.

### Custom From Name
A new **From Name (optional)** field in the Gmail Authorization card. When filled in, emails arrive as `Label Name <you@domain.com>` instead of a bare address. Server constructs the proper RFC 2822 display-name format.

## Infrastructure

### Feature Branch Workflow
Switched to a PR-based feature branch workflow. All new work goes on `feat/...` branches and merges via pull request.

### Session Persistence (Firestore)
Replaced the default in-memory `express-session` store with a custom Firestore-backed store (`firestoreSessionStore.js`). Sessions now survive Cloud Run restarts and work correctly across multiple instances.

- Enabled Firestore API in GCP project `elegant-cipher-497621-m4`
- Created Firestore database in `us-central1` (free tier)
- Sessions stored at `sessions/{sessionId}` with lazy expiry cleanup

### SMTP Email Transport (`feat/smtp`)
Replacing the Gmail OAuth send flow with **nodemailer SMTP** — works with any email provider (Gmail, Outlook, custom label domain, etc.). In progress on `feat/smtp`.

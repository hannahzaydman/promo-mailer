# Updates — May 29, 2026

## New Features

### Embargo Note (per-release checkbox)
Each release card in Step 2 now has an optional **Add embargo note** checkbox. When checked, a small muted paragraph is appended to every email in that release:

> *"This is a promo copy — please don't share or post the files until release day. Thanks for supporting the music."*

No DRM, no watermarking — just a friendly ask. Works for pre-release campaigns where the Bandcamp album is set to Private.

### Attribution Footer
Every outgoing email now includes a small footer line:

> *Sent with [djpromo.net](https://djpromo.net), a tool by [Midnight Ecstasy](https://midnightecstasy.bandcamp.com)*

Always appended, regardless of embargo setting.

### Sign-in Page Feature Highlights
The login page now shows four bullet points above the Google sign-in button, explaining what makes djpromo.net different:

- **Sends from your label's Gmail** — every DJ gets a personal email straight from your address
- **Bandcamp download codes** — one unique code per DJ, works with private pre-release albums
- **One link, one click** — DJs redeem their code instantly, nothing to install
- **Your own contact list** — bring your DJ list as a spreadsheet, you stay in control

### Bandcamp Private Album Warning
A hint below the Download Codes upload field on each release card warns users to lock their Bandcamp album URL slug before generating codes — changing it after the fact breaks all previously issued codes.

## Bug Fixes

### Session Expiry Crash on Preview
When a user's session expired while they were on the Releases page and then clicked Next, the server threw `Cannot read properties of undefined (reading 'email')` inside the `/preview` route's try-catch. The raw JavaScript TypeError was returned as the error message and shown in the UI.

**Fix:** Added explicit `401` guards in `/preview` and `/send` before accessing `req.session.user`:
```
Session expired. Please sign out and sign in again.
```

### Null Row Guard in XLSX Parsing
Some XLSX edge cases (blank trailing rows, certain Excel export formats) could produce `null` or `undefined` entries in parsed spreadsheet rows. Added a filter in `readSpreadsheet()` to drop these before they reach column validation or recipient/code parsing. The same guard was applied to `parseRecipientList()` and the codes file parser in the preview route.

## Infrastructure

### Multi-Tenancy Shipped
All multi-tenancy groundwork is now live in production (`main`):

- `ALLOWED_DOMAIN` env var removed from production — any Google account can sign in
- Gmail tokens stored per-session (each user authorizes their own Gmail)
- Firestore session store (sessions survive Cloud Run restarts and scale across instances)
- Unsubscribe links in every email, backed by Firestore
- Recipient deduplication at preview time
- Daily Gmail send count tracking with a soft limit warning

### Google OAuth Verification In Progress
Privacy policy live at `djpromo.net/privacy`. Terms of service at `djpromo.net/terms`. OAuth consent screen submitted for Google verification — awaiting review (3–5 business days). Removes the "unverified app" warning for non-`@midnightecstasy.com` users.

### CI (GitHub Actions)
Added `.github/workflows/ci.yml` — runs `node --test` on every push to `develop` and `main`.

Gmail Authorization

Setup instructions (one-time)
  1. Go to console.cloud.google.com and create a new project (or select an existing one).
  2. Search for Gmail API and enable it.
  3. Go to APIs & Services → OAuth consent screen.
    Set User Type to Internal (Google Workspace — no verification required).
  4. Go to Credentials → Create Credentials → OAuth client ID.
    Application type: Web application.
    Under Authorized redirect URIs, add: http://localhost:5001/auth/callback
  5. Copy your Client ID and Client Secret into the fields below.
